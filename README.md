## Automated Version setup
If you want an automated version of the script after downloading all the files run:
```bash
bash install-lazyvim.sh 
```



> [!IMPORTANT]
> Depending on the architeture of your CPU there are different scripts, to check your CPU architeture run:
> ```bash
> uname -m
> ```


## Architecture x86_64 

If your CPU architeture is x86_64:
Download the file [setup-lazyvim-x86_64](scripts/setup-lazyvim-x86_64.sh).
After dowloading the file run: 

```bash
bash setup-lazyvim-x86_64.sh 
```

## Architecture arm64/aarch64

If your CPU architeture is aarch64/arm64:
Download the file [setup-lazyvim-aarch64](scripts/setup-lazyvim-aarch64.sh).
After downloading the file run:

 ```bash
bash setup-lazyvim-aarch64.sh
 ```
